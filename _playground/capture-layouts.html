Echo — Capture Window Layout Playground

Eight layout proposals for the capture window. The current design wastes vertical space, has a tiny drag region, and crams controls into one cramped row. Each variant explores a different tradeoff: drag-region, input prominence, controls hierarchy, and the meeting-vs-quick-note distinction. Toggle the to see where each layout lets you grab the window.
